# Phase 1.5 — Frontend Consolidation Migration Map

## Scope

The root `client/` is the single active frontend. The former `frontend-web/`
tree was audited as a historical reference and removed after confirming that
the active application had no dependency on it. This migration does not modify
backend services, analyzer algorithms, or dictionaries.

## Migration map

| Source | Destination | Action | Result |
| --- | --- | --- | --- |
| `frontend-web/client/App.tsx` | `client/App.tsx` | KEEP | Root routing is authoritative and includes all legacy game routes plus `/analyzer` routes. |
| `frontend-web/client/components/AppShell.tsx` | `client/components/AppShell.tsx` | KEEP | Root shell preserves game navigation and adds the Analyzer navigation entry. |
| `frontend-web/client/components/ScrabbleBoard.tsx` | `client/components/ScrabbleBoard.tsx` | KEEP | Root board is authoritative and uses shared tile/premium definitions. |
| `frontend-web/client/lib/game-data.ts` | `client/lib/game-data.ts` | KEEP | Root game data is authoritative and reuses `shared/tiles.ts` and `shared/premiums.ts`. |
| `frontend-web/client/pages/{Index,NewGame,OngoingGames,Game,History,Settings,NotFound}.tsx` | `client/pages/` | KEEP | All historical game routes are already present in the root application. Root `Game.tsx` remains authoritative. |
| `frontend-web/client/components/ui/*` | `client/components/ui/*` | REUSE | All overlapping UI primitives are already present in the root tree; no duplicate copy was needed. |
| `frontend-web/client/hooks/{use-mobile,use-toast}.tsx` | `client/hooks/` | REUSE | Existing root copies are identical. |
| `frontend-web/client/lib/utils.{ts,spec.ts}` | `client/lib/` | REUSE | Existing root copies are identical. |
| Root Analyzer pages/components/hooks/libs | `client/` | KEEP | Analyzer implementation remains unchanged and authoritative. |
| `frontend-web/client/.DS_Store` | — | SKIP | Non-source metadata; not migrated. |

## Audit results

- No source file required a safe merge from `frontend-web/client/` into root;
  the game surface is already consolidated in root.
- Root-only Analyzer files are preserved.
- No active client, server, or build-config import references `frontend-web/`.
- The audited legacy `frontend-web/` tree has been removed.
- No backend or server files were changed.

## Verification checklist

- Routes present: `/`, `/new-game`, `/games`, `/games/:gameId`, `/history`,
  `/settings`, `/analyzer`, `/analyzer/upload`, `/analyzer/processing`,
  `/analyzer/results`, `/analyzer/error`.
- Static source audit: passed for absence of `frontend-web/` references in the
  active client.
- `pnpm typecheck`: not runnable in the current workspace because the local
  `tsc` executable is missing.
- Production build and Vitest: pending dependency/toolchain availability; no
  source changes were made to manufacture a passing result.
