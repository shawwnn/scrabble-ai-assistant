## Scoring Engine Update — Processing Flow

```text
DICTIONARY APPROVED
        │
        ▼
┌─────────────────────────────┐
│ 1. Receive formedWords      │
│    from words.ts            │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 2. scoreMove()              │
│    Calculate each word      │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 3. scoreWord()              │
│    Score every tile         │
│    + premiums               │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 4. Determine bingo          │
│    Count unique pending     │
│    tiles                    │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 5. Calculate total          │
│    word scores + bingo      │
└──────────────┬──────────────┘
               │
               ▼
        ScoreResult
               │
               ▼
┌─────────────────────────────┐
│ 6. validateMove.ts          │
│    Build final API response │
└─────────────────────────────┘
```

### Stage 1 — Dictionary-approved words enter scoring

**Input**

The dictionary process has already confirmed that every formed word is valid.

```ts
result = {
  valid: true,
  invalidWords: [],
  dictionary: "UK",
};
```

At this point:

```ts
formedWords;
```

contains the words generated by `getWordsFromMove()`.

Each word contains:

```ts
{
  word: string,
  positions: string[],
  tiles: CurrentMoveTile[]
}
```

For example:

```ts
[
  {
    word: "BE",
    positions: ["H8", "H9"],
    tiles: [
      {
        key: "H8",
        letter: "B",
        tile: {
          pending: true,
          wildcard: true,
        },
      },
      {
        key: "H9",
        letter: "E",
        tile: {
          pending: true,
        },
      },
    ],
  },
];
```

**Process**

`validateMove.ts` calls:

```ts
const scoreResult = scoreMove(formedWords);
```

**Output**

```ts
scoreResult;
```

with:

```ts
{
  totalProjectedScore: number,
  words: WordScore[],
  bingo: boolean
}
```

---

# Stage 2 — `scoreMove()` receives all formed words

### Input

```ts
formedWords: FormedWord[]
```

Example:

```ts
[
  {
    word: "BE",
    positions: ["H8", "H9"],
    tiles: [...]
  },
  {
    word: "OB",
    positions: ["H9", "I9"],
    tiles: [...]
  }
]
```

### Process

`scoreMove()` processes **each formed word independently**:

```ts
const words = formedWords.map((formedWord) => ({
  word: formedWord.word,
  score: scoreWord(formedWord),
}));
```

This means:

```text
formedWords
    │
    ├── "BE" → scoreWord()
    │
    └── "OB" → scoreWord()
```

### Output

```ts
words = [
  {
    word: "BE",
    score: 4,
  },
  {
    word: "OB",
    score: 4,
  },
];
```

The important thing here is that **each word gets its own score before the total is calculated**.

---

# Stage 3 — `scoreWord()` scores the individual tiles

This is the core scoring stage.

### Input

One `FormedWord`:

```ts
{
  word: "BE",
  positions: ["H8", "H9"],
  tiles: [...]
}
```

The function loops through:

```ts
for (const tile of formedWord.tiles)
```

Each tile is processed individually.

---

# Stage 4 — Determine the base tile value

For every tile:

```ts
getTilePoints(tile);
```

is called.

### Normal tile

Input:

```ts
{
  letter: "E",
  tile: {
    pending: true
  }
}
```

Process:

```text
E
↓
TILE_POINTS["E"]
↓
1
```

Output:

```ts
1;
```

---

### Blank / wildcard tile

This is the important scoring-engine update.

Input:

```ts
{
  letter: "B",
  tile: {
    pending: true,
    wildcard: true
  }
}
```

The represented letter is `B`, but the tile itself is a wildcard.

Process:

```ts
if (tile.tile["wildcard"] === true || tile.tile["isBlank"] === true) {
  return 0;
}
```

Therefore:

```text
represented letter = B
actual tile         = blank
                     ↓
                   0 points
```

Output:

```ts
0;
```

So the scoring engine **does not use the represented letter alone to determine the score**.

It first determines:

```text
Is this a blank?
      │
      ├── YES → 0 points
      │
      └── NO  → use TILE_POINTS[letter]
```

This is the key correction to the previous scoring behavior.

---

# Stage 5 — Determine whether the tile can activate a premium

After obtaining the base tile value:

```ts
let tileScore = getTilePoints(tile);
```

the scoring engine checks:

```ts
isPending(tile);
```

### Input

```ts
tile.tile["pending"];
```

### Process

```ts
function isPending(tile) {
  return tile.tile["pending"] === true;
}
```

### Output

Either:

```text
true
```

or:

```text
false
```

This establishes the rule:

> **Only tiles placed during the current move can activate premium squares.**

Therefore:

```text
Existing tile
    ↓
pending = false
    ↓
premium ignored
```

while:

```text
Newly placed tile
    ↓
pending = true
    ↓
premium may apply
```

---

# Stage 6 — Determine the premium from the board position

For a pending tile:

```ts
const premium = getPremium(tile.key);
```

### Input

```ts
tile.key;
```

Example:

```ts
"H8";
```

### Process

The scoring engine asks the board definition:

```text
What premium belongs to H8?
```

Possible output:

```ts
"DL";
```

or:

```ts
"TL";
```

or:

```ts
"DW";
```

or:

```ts
"TW";
```

or:

```ts
undefined;
```

The important architectural decision is:

> **Premiums belong to board coordinates, not to tiles.**

So the tile does not need to contain:

```ts
tile.premium;
```

Instead:

```text
tile.key
   ↓
board coordinate
   ↓
getPremium()
   ↓
premium
```

---

# Stage 7 — Apply the premium

The scoring engine then applies the premium.

### Double Letter

```ts
case "DL":
  tileScore *= 2;
```

Example:

```text
E = 1
DL
↓
1 × 2
↓
2
```

### Triple Letter

```text
E = 1
TL
↓
1 × 3
↓
3
```

### Double Word

Unlike DL/TL, this does **not** immediately multiply the tile.

Instead:

```ts
wordMultiplier *= 2;
```

Example:

```text
tile values = 3 + 1
DW = ×2

3 + 1 = 4
4 × 2 = 8
```

### Triple Word

```ts
wordMultiplier *= 3;
```

---

# Stage 8 — Accumulate the word's tile scores

For every tile:

```ts
wordScore += tileScore;
```

So the processing becomes:

```text
Tile 1
  ↓
base value
  ↓
blank check
  ↓
pending check
  ↓
premium check
  ↓
tile score
  │
  ▼
wordScore

Tile 2
  ↓
base value
  ↓
blank check
  ↓
pending check
  ↓
premium check
  ↓
tile score
  │
  ▼
wordScore

...
```

After all tiles:

```ts
return wordScore * wordMultiplier;
```

### Output

A single numeric score:

```ts
scoreWord(formedWord);
```

returns:

```ts
number;
```

Example:

```ts
8;
```

---

# Stage 9 — Produce the individual word scores

Back inside `scoreMove()`:

```ts
const words = formedWords.map(...)
```

The output becomes:

```ts
[
  {
    word: "BE",
    score: 4,
  },
  {
    word: "OB",
    score: 4,
  },
];
```

This is the **per-word scoring result**.

---

# Stage 10 — Calculate the total word score

The engine now combines the individual word scores:

```ts
const totalWordScore = words.reduce((total, word) => total + word.score, 0);
```

### Input

```ts
[
  { word: "BE", score: 4 },
  { word: "OB", score: 4 },
];
```

### Process

```text
4 + 4
↓
8
```

### Output

```ts
totalWordScore = 8;
```

---

# Stage 11 — Determine whether the move is a bingo

The engine must not count occurrences of tiles inside words because one newly placed tile can participate in multiple words.

Instead:

```ts
const pendingKeys = new Set<string>();
```

For every formed word:

```ts
if (isPending(tile)) {
  pendingKeys.add(tile.key);
}
```

### Input

All tiles belonging to all formed words.

### Process

```text
formed words
     ↓
all tiles
     ↓
pending tiles only
     ↓
unique tile.key values
     ↓
Set
```

For example:

```ts
Set {
  "H8",
  "H9",
  "H10",
  "H11",
  "H12",
  "H13",
  "H14"
}
```

### Output

```ts
pendingKeys.size = 7;
```

Therefore:

```ts
const bingo = pendingKeys.size === 7;
```

Output:

```ts
bingo = true;
```

---

# Stage 12 — Apply the bingo bonus

The engine calculates:

```ts
const totalProjectedScore = bingo ? totalWordScore + 50 : totalWordScore;
```

### Without bingo

```text
totalWordScore = 8
bingo = false

8 + 0
↓
8
```

Output:

```ts
totalProjectedScore = 8;
```

### With bingo

```text
totalWordScore = 42
bingo = true

42 + 50
↓
92
```

Output:

```ts
totalProjectedScore = 92;
```

---

# Stage 13 — Final `scoreMove()` output

The complete scoring engine returns:

```ts
{
  (totalProjectedScore, words, bingo);
}
```

Example:

```ts
{
  totalProjectedScore: 8,
  words: [
    {
      word: "BE",
      score: 4
    },
    {
      word: "OB",
      score: 4
    }
  ],
  bingo: false
}
```

This is the **complete output of the scoring engine**.

# Stage 14 — Return through `validateMove.ts`

`validateMove.ts` takes the scoring result and constructs the API response.

### Input

```ts
scoreResult = {
  totalProjectedScore: 8,
  words: [
    { word: "BE", score: 4 },
    { word: "OB", score: 4 },
  ],
  bingo: false,

```

### Process

```ts
return res.json({
  status: "valid",
  totalProjectedScore: scoreResult.totalProjectedScore,
  words: formedWords,
  invalidWords: [],
  reason: null,
  dictionary: result.dictionary,

```

```json
{
```

### The key scoring-engine update

The most important conceptual change you're documenting is this:

```text
OLD / incorrect assumption

letter → points


NEW / correct scoring model

actual tile
    │
    ├── blank/wildcard?
    │       └── YES → 0
    │
    └── NO
         │
         ▼
       letter
         │
         ▼
      tile points
         │
         ▼
   pending tile?
      │       │
     NO      YES
      │       │
      │       ▼
      │    board coordinate
      │       │
      │       ▼
      │     premium
      │       │
      └───────┴──→ final tile contribution
```
